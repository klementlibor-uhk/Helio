# Písmo Inter

Soubory `inter-latin.woff2` a `inter-latin-ext.woff2` jsou podmnožiny proměnného
písma **Inter** (latinka a rozšířená latinka), vytvořené pro Google Fonts.

- Autor: Rasmus Andersson

- Zdroj a plné znění licence: <https://github.com/rsms/inter>

Písmo je uložené přímo v repozitáři schválně: test tím nemusí při otevření nic
stahovat z cizích serverů, takže se o žákovi nikdo nedozví ani to, že úlohu
otevřel. Licence OFL takové šíření výslovně dovoluje; písmo se neprodává ani
nevydává pod jiným jménem.
